## Supervised Learning Algorithms

### Linear Regression

Predicts continuous values using a linear relationship between input features and target variables.

**Concepts Covered**

* Simple Linear Regression
* Multiple Linear Regression
* Model Evaluation
* R² Score
* Mean Squared Error

---

### Logistic Regression

Used for binary and multi-class classification problems.

**Applications**

* Spam Detection
* Disease Prediction
* Customer Churn Prediction

---

### K-Nearest Neighbors (KNN)

A distance-based classification and regression algorithm.

**Concepts Covered**

* Euclidean Distance
* Classification
* Regression
* Hyperparameter Tuning

---

### Support Vector Machine (SVM)

Creates optimal decision boundaries for classification tasks.

**Applications**

* Image Classification
* Text Classification
* Bioinformatics

---

### Decision Trees

Tree-based model for classification and regression.

**Concepts Covered**

* Information Gain
* Entropy
* Gini Index
* Tree Pruning

---

### Random Forest

Ensemble learning method using multiple decision trees.

**Benefits**

* High Accuracy
* Reduced Overfitting
* Feature Importance Analysis

---

### Naive Bayes

Probabilistic classifier based on Bayes' Theorem.

**Applications**

* Sentiment Analysis
* Email Filtering
* Document Classification
